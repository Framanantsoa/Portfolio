# Portfolio
Portfolio personnel de **François ANDRIAMANANTSOA**, développeur Full-Stack Junior (.NET / JS).

## Aperçu

Site statique en une seule page, construit sans framework JS, avec :

- HTML5 sémantique
- Tailwind CSS (via CDN)
- JavaScript vanilla pour : menu mobile, bascule FR / EN, animations au scroll
- Thème sombre unique
